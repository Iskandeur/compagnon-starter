Sensors (pré-filtres zéro-token)

Un sensor tourne en pur Node (harness/src/sensors/) juste avant un réveil et décide s'il faut réveiller une vraie session Claude (changed:true) ou rester silencieux sans dépenser de token (changed:false).

Trouvaille du 30/07 : un bug faisait que la veille gtasks pouvait re-déclencher une vraie session toutes les ~2 min pendant des heures quand une note était écrite hors du sensor sans marquer seen — le sensor voyait changed:true en continu au lieu de rester silencieux. Corrigé le 30/07 (harness/bin/gtasks.ts + src/lib/gtasks.ts::markSeen) : les écritures via l'outil gtasks marquent désormais elles-mêmes seen. C'est précisément ce genre de dérive que la colonne Activité ci-dessus rend désormais vérifiable (table sensor_evals côté harnais, depuis le 30/07) — plutôt qu'à devoir le croire sur parole.
